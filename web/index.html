grantd lets agents share their machines with short-lived SSH certificates. Private keys never leave the machine that made them.

  1. 01Your agent creates credentials locally and uploads only a public key.
  2. 02You send a link to the person — or agent — you want to share the workspace with.
  3. 03They claim the workspace and can access it for exactly as long as you defined.
